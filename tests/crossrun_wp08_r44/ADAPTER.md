# WP-08 R44 public adapter contract

At issued Product main `788cb765493096a076603e5ad4ac6e2dea47a7a9` / engine tree `054d27ab6e3e72f61118ff7d99e19e48741d05b2`, build a standalone adapter without importing this oracle. Construct one Side B raw index with **four distinct consecutive timeline runs** of lengths 5, 3, 7 and 2, mapped to independently allocated non-overlapping physical chunk ranges. Write exact little-endian interleaved stereo PCM from `oracle.fixture()` into those chunks, including the short final run; use a valid DRAFT-9 superblock/index CRC. Hash the 17 logical frames and report their SHA-256. This fixture is intentionally nonconstant, so a stale ring/run sample cannot masquerade as a neighbor.

For every `oracle.cases()` entry, start from a fresh mount, `tape_seek(case.seek)`, `tape_set_rate(case.rate)`, service to completion, then render the same logical requested output with three subdivisions: `whole` (one render, service budget 256), `single` (one frame/render, budget 1), `uneven` (3/2 frame chunks, budget 7). For each variant, reset/mount before seeking so the ring and transport state are independent. Record each `tape_service` call's budget, actual callback block count, `more_work`, result; keep calling until `more_work=false`. Record each `tape_render` call's requested/rendered frames, exact output PCM hex, result, `tape_tell` whole frame and `tape_status` endpoint flags immediately after it. `block_events` contains callback events *during render only* and must be empty. No hidden position or implementation interpolation labels are permitted. The oracle derives fractional Q32.32 position, floor interpolation and endpoint state independently.

Emit one JSONL object per case, `schema: "wp08-r44-v1"`, `case`, `fixture_sha256`, `run_lengths`, `seek`, `rate`, `variants` with `whole`, `single`, `uneven`; each variant has `render_sizes`, `service_budget`, `services`, `renders`. See `selftest.observation()` for an example schema, but do not use its synthetic outputs as Product evidence. `replay.py` demands all 33 IDs exactly once and binds the unabridged trace, oracle, plan, adapter source and Product SHA/tree in a non-overwriting manifest. Retain the adapter source/build command and raw fixture image separately; report any missing public `tell`/status/budget visibility as a concrete blocker rather than reading private engine fields.
