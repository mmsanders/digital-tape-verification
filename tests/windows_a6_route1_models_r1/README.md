## Interface correction1/2 — all five points before full clearance

Direct [609 handoff6455984085](https://github.com/mmsanders/Digital-Tape/issues/609#issuecomment-6455984085)
consolidates the following. No native trial is required to answer this declaration.

1. **Ordinary workload, admin recorder:** declare the existing ordinary-terminal
   operator/launch step and own-token guard separately from any future human admin
   recorder. [CreateProcess](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-createprocessw)
   ordinarily uses the calling process's security context. An admin-launched child
   cannot merely be labelled Medium. No token manipulation/elevation workaround.
2. **Basic/simple mapping:** one disk extent does not prove basic/nonlayered storage.
   [Basic/dynamic storage](https://learn.microsoft.com/en-us/windows/win32/fileio/basic-and-dynamic-disks)
   is distinct from physical disk and partition style; dynamic simple volumes exist.
   Declare positive supported-layout metadata evidence or STOP_LAYOUT_UNSUPPORTED.
   [Volume disk extents](https://learn.microsoft.com/en-us/windows/win32/api/winioctl/ni-winioctl-ioctl_volume_get_volume_disk_extents)
   supplies physical locations, not that complete storage classification.
3. **Allocation before baseline:** CREATE_NEW starts empty. Declare ordinary-file
   preparation/allocation before the BEFORE map, covering the entire measured2MiB
   intervals with bound FileId/length/allocation and AFTER comparison. An empty
   before-map becoming an allocated after-map is not stability. No privileged
   SetFileValidData, sparse shortcut or unbounded allocation. Before/after equality
   is a detecting consistency condition, not proof against every unseen relocation.
4. **Actual schemas/profile:** provide exact profile/buffer definition, supported
   provider GUID/opcode/version/pointer-header/export shapes and loss/window
   semantics. OS x64 is not a substitute for native header/payload validation.
   Do not guess a raw layout or reinterpret missing data as zero. Named decoded
   EventData versus raw EventPayload require explicit separate qualification;
   unsupported versions/lengths/fields STOP_SCHEMA_UNKNOWN. The
   [WPR SystemProvider](https://learn.microsoft.com/en-us/windows-hardware/test/wpt/systemprovider)
   definition describes configuration, not emitted edges on a given stack.
5. **Unbuffered alignment:** declare memory-buffer allocation/address checks and
   supported alignment metadata, as well as sizes/offsets. Microsoft distinguishes
   [logical-sector lengths and physical-sector buffer alignment](https://learn.microsoft.com/en-us/windows/win32/fileio/file-buffering).
   A ctypes byte buffer is not proven aligned just because writes are512KiB.
   Unknown alignment is STOP. No broader volume/disk data access is licensed.
