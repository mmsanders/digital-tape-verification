## Verifier contradiction and correction

The published adapter contract requires the wrapper to record **every** block callback. `WP09-ARMED-BUSY` necessarily mounts Side B before the armed-state probes, and the retained product trace contains 13 mount-phase reads.

The published oracle instead required:

```python
req(not events, "armed BUSY/abort path issued block I/O")
```

That made the published package internally contradictory: a contract-conforming adapter that retained required mount reads could not pass the case.

The corrected oracle preserves the intended property without filtering evidence:

```python
req(not any(e.get("phase") in ("armed", "abort", "unmount") for e in events),
    "armed BUSY/abort/unmount path issued block I/O")
```
